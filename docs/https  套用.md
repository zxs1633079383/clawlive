
# 终端运行（启动 dev + 两个 SSL 代理）
pnpm dev:ssl

然后手机访问：https://196.168.1.177:3443（注意是 https 和端口 3443）

第一次访问会提示证书不受信任，点"高级"→"继续访问"即可。

┌──────┬───────┬───────────────────────┐
│ 端口 │ 协议  │         用途          │
├──────┼───────┼───────────────────────┤
│ 3000 │ HTTP  │ UI（PC 本地开发）     │
├──────┼───────┼───────────────────────┤
│ 3001 │ HTTP  │ API + WS              │
├──────┼───────┼───────────────────────┤
│ 3443 │ HTTPS │ UI（手机访问用这个）  │
├──────┼───────┼───────────────────────┤
│ 3444 │ HTTPS │ API + WSS（自动适配） │
└──────┴───────┴───────────────────────┘
